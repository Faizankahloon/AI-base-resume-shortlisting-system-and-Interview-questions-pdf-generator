# AI-base-resume-shortlisting-system-and-Interview-questions-pdf-generator

An AI-powered web application that automatically shortlists resumes based on job requirements and generates customized interview question PDFs for HR to conduct interviews of shortlisted candidates.

## Tech Stack

- React
- Vite
- Flask
- SQLite

## Setup

Install frontend dependencies:

```bash
npm install
```

Run the frontend:

```bash
npm run dev
```

Backend environment variables should be stored in `src/backend/.env`.
